# Data provenance

Every value in OutfallWatch carries a source label. This document states exactly where
each kind of data comes from and how it is marked.

## Source labels

| Label | Meaning | Where |
| --- | --- | --- |
| `HARDWARE` | real ESP32-S3 sensor reading | `SensorReading.source` |
| `SIMULATION` | virtual device, seeded synthetic signal | `SensorReading.source` |
| `IMPORTED_OFFICIAL` | authentic official observation | `ExternalObservation.data_kind` |
| `TEST_FIXTURE` | offline example / fallback, **never live** | both tables |

## Prototype sensor data

- **SIMULATION:** generated by `app/simulation/scenarios.environment(scenario, seed,
  intensity)` — deterministic, seeded. The turbidity index is a **0–100 relative demo
  index**, not NTU. Conductivity is left `null` (optional sensor absent) — shown as
  "Unavailable", never 0.
- **HARDWARE:** two-point calibrated relative index from the turbidity module; DS18B20 °C
  if present; raw mV preserved. Calibration id/date/references stored in `Calibration`.

These are the only data fed to the detection engine. Official data is **never** fed in.

## Official / external observations

| Provider | Identifier | Temporal | Units | Quality flags | Provenance |
| --- | --- | --- | --- | --- | --- |
| NOAA | station 8775296 (USS Lexington, Corpus Christi Bay) | real-time latest + historical 24 h (hourly) | ft (water level) | CO-OPS `q` flag | datagetter API; `source_url` stored. Offline → fixture labelled `TEST_FIXTURE`. |
| GCOOS | ERDDAP CBI_042 (Conrad Blucher Institute) | latest non-null per metric | °C, PSU, mg/L, µg/L, NTU, m | ERDDAP QC | live tabledap; independent CBI data (not NOAA-republished). Offline → fixture labelled `TEST_FIXTURE`. |

_Scope: only NOAA + GCOOS. TCEQ, Open-Meteo, GBIF, iNaturalist, NASA Earthdata and
OpenWeatherMap were removed by request._

## Honesty rules enforced

- Fixtures are labelled `TEST_FIXTURE` and surfaced as "FIXTURE" in the UI — never "LIVE".
- NOAA and GCOOS fixtures are offline fallbacks only; the live fetch replaces them and flips
  the status to WORKING with `IMPORTED_OFFICIAL` rows.
- Historical official records are shown on a separate page from the live sensor series and
  are never charted as if they were prototype readings.
- NOAA stations are context, **not** a measurement of the demo outfall.
- No official water measurements, pollution concentrations, model accuracies, or energy
  savings are invented. Energy figures are explicitly `ESTIMATED` (GREEN_AI.md).
